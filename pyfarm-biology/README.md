# pyfarm-biology

Fermentation, incubation, and lab assay specs for the pyfarm ecosystem.

Part of the pyfarm multi-domain ecosystem. Install alongside `pyfarm-core` to get:

```
pyfarm bio validate examples/kombucha_batch.bio.yaml
pyfarm bio start examples/yogurt_culture.bio.yaml
```

## Domains

- Fermentation (kombucha, beer, wine, vinegar)
- Microbial cultures (yogurt, kefir, sourdough)
- Lab incubation (cell culture, plate assays)
- Any process driven by temperature, pH, dissolved oxygen, or agitation
